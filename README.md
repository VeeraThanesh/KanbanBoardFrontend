# Task Management App (Kanban Board)

A simple task management application to track tasks in different stages like **To Do**, **In Progress**, and **Done**.  

This app helps users organize and manage their workflow efficiently.

---

## Features

- Create, edit, and delete tasks
- Move tasks between stages:
  - **To Do**
  - **In Progress**
  - **Done**
- Track task status at a glance
- Simple and intuitive UI

---

## Kanban Board Structure

| Stage         | Description                                  |
|---------------|----------------------------------------------|
| **To Do**     | Tasks that need to be started                |
| **In Progress** | Tasks currently being worked on             |
| **Done**      | Completed tasks                              |
